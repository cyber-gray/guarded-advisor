## Known gaps

- **Container Apps Sandboxes** have no meter in the Retail Prices API and no billing section on Learn yet. The overview says stopped sandboxes incur no CPU or memory fees (https://learn.microsoft.com/azure/container-apps/sandboxes-overview). The lines above use the Container Apps Consumption vCPU and memory rates as a proxy. Check actual cost in Cost Management after the first runs (`w2-sbx-tool`).
- **Defender for AI Services and Defender CSPM** returned no Canada East meters. Check pricing on Learn before enabling them outside the trial (`w2-defender`).
- Not priced (expected to be under 1 CAD each): Key Vault operations, Storage account capacity and transactions, private endpoint data processing, Logic App runs, embeddings (text-embedding-3-small rounds to 0.0000 per 1K tokens).
- Spectre (another project on the subscription) isn't included; the lab budget is scoped to `rg-guardedadvisor-lab`.
