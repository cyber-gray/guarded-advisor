# Graduated return-to-work plan: template

Larkfield Mutual (fictional). Synthetic document for the Guarded Advisor lab.

**Label every draft:** "AI-generated draft for case manager review. Not a decision."

| Field | Content |
|---|---|
| Claim ID | |
| Case manager | |
| Start date | |
| Current restrictions | From the latest APS, quoted with its date |
| Modified duties | Agreed with the employer |
| Week 1 | Hours a day, days a week, duties |
| Week 2 | |
| Week 3 | |
| Week 4 | |
| Review points | End of week 1, then every 2 weeks |
| Supports | Accommodations, treatment appointments during work hours |
| Sources | Fields and documents the draft relied on (claim fields, APS date, employer statement) |

The case manager edits the draft, records the final plan and owns the decision. The draft and the final plan are
kept separately so the agree/override rate can be measured.
